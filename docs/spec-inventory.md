# Matrix v1.19 homeserver spec inventory

Authoritative requirement inventory for Conduit against [Matrix v1.19](https://spec.matrix.org/v1.19/). Machine-readable twin: [`spec-inventory.json`](spec-inventory.json). Snapshot of `main` at `8e301e5`; spec pages fetched 2026-10-14. Owner bead: `conduit-y99.3`.

Statuses: **tested** = present and asserted by a named test; **untested** = present, no test; **partial** = present with a known deviation (see bead); **missing** = absent; **n/a** = not a homeserver obligation (justified). Endpoint presence is not semantic conformance: a "tested" row means the named tests assert behaviour, not that every clause of the endpoint is proven. Every partial/missing row names at least one gap bead.

## How this was built

- Endpoints: every `<h1>` carrying an HTTP method on the client-server, server-server, application-service, push-gateway and identity-service pages (164/36/11/1/23; 9 client-server endpoints are deprecated-but-present and in scope). Cross-checked against each page's endpoint TOC.
- Requirements: every normative module/section of those pages that places behaviour on a homeserver, room versions 1-12 (event format, auth rules, redaction, state resolution, canonical JSON per version), and every appendix section.
- Code: axum `.route(...)` calls under `conduit-server/src` (federation router nested at `/_matrix/federation/v1|v2`); outbound client calls for AS/push/IS were located by hand.
- Tests: literal request paths and handler names inside `#[test]`/`#[tokio::test]` bodies (incl. shared helpers), filtered by HTTP method, then curated.

## Maintaining this inventory

When a lane lands work, update the affected rows (status, code, tests, gap_beads) in both `spec-inventory.json` and this file, and the summary counts. A row may only move to `implemented+tested` with a named test that asserts the spec behaviour. The register entry `complete-server-requirement-inventory` in `matrix-compliance.json` points here; `full_compliance_proven` stays false until every non-n/a row is tested.
