# Learnings

Append-only. One line per hard-won fact. Dated, with a file reference.

- 2026-09-10 — `iroh` pulls `http`/`reqwest` transitively (iroh-relay); `axum` never in `cargo tree -p conduit`. Embeddable means tokio-hosted, not runtime-agnostic. (`openspec/specs/embeddable-kernel/spec.md`)
- 2026-10-13 — Federation v2 is a path prefix, not a suffix after the endpoint name. Share the production mount/auth builder with tests; signatures must cover `OriginalUri` through both nested routers. (`conduit-server/src/federation/server.rs`)
- 2026-10-13 — HTTP 200 from a federation transaction can contain per-event errors. Message fixtures need create/member auth state and must assert the PDU result before checking persistence. (`conduit-server/tests/federation_inbound.rs`)
- 2026-10-13 — Device-list changes and to-device queue IDs are independent streams. Delete queue entries only when the next request acknowledges their delivered cursor; premature deletion loses verification/encryption messages on retries. (`conduit-server/src/api/client/sync.rs`)
- 2026-10-13 — Sync notifications need their own channel: publishing a fake room position wakes push/AS workers and can reprocess an unrelated event. Enable Notify before reading durable streams; treat every notification as a hint to rebuild visible deltas. (`conduit-server/src/api/client/sync.rs`)
- 2026-10-13 — PostgreSQL account-data/receipt upserts must replace stream_pos with EXCLUDED.stream_pos. Returned row counts are not cursor positions, and the correct partial unique index must be selected before a per-room insert. (`conduit-server/src/storage_pg.rs`)
- 2026-10-13 — The production RoomEventSender must not emit position zero after the persist pipeline already broadcasts the real position: push and AS workers interpret each position as an event lookup. (`conduit-server/src/main.rs`)
- 2026-10-13 — To-device federation uses m.direct_to_device EDUs, not a send_to_device endpoint. Preserve the Matrix sender ID and a stable message ID of at most 32 Unicode codepoints; validate sender domain against authenticated origin. Verified with live Synapse 1.162.0 over private-CA TLS. (`conduit-server/tests/peers/synapse_to_device.py`)
- 2026-10-13 — Cache lookup plus later insertion cannot deduplicate concurrent sends. Commit the successful result and event/local queue/remote outbox in one storage transaction; expand wildcards only in that commit. Fault injection proved rollback of the marker and all effects together. (`conduit-server/tests/storage_pg.rs`)
- 2026-10-13 — A saved result is insufficient for interrupted federation batches: pin the first authenticated body, serialize the full HTTP transaction, and resume its incomplete work after transient failure. Keep lifetime advisory locks on a separate pool to avoid starving the connections needed by guarded writes. (`conduit-server/src/replay.rs`)
- 2026-10-13 — Biscuit 6 defaults to a 1ms wall-clock Datalog limit. Concurrent builds reproduced valid-token rejections. Set the builder evaluation deadline explicitly for both claim queries and authorization, retain default fact/iteration bounds, and stress valid tokens plus fail-closed oversized rule generation. (`conduit/src/agency.rs`)
- 2026-10-13 — DAG depth is not stream order. MemoryStorage needs independent insertion positions for events, membership history, pagination and atomic writes; duplicates must not mutate or advance them. Preserve deleted positions across PG purges with a transactionally updated retired watermark. (`conduit/src/storage.rs`)
- 2026-10-13 — Sync state precedes the timeline. Tests acting as clients must fold timeline state events; expecting every create/join in the state array duplicated events. prev_batch must address the position before the truncated timeline, not since or depth. (`conduit-server/src/api/client/sync.rs`)
- 2026-10-14 — Matrix filter limits must be positive; the previous zero-limit convenience was nonconformant and is now rejected. Empty allowlists differ from absent lists, exclusions win, and type wildcard syntax treats regex punctuation literally. (`conduit/src/filter.rs`)
- 2026-10-14 — Filter before field projection. Lazy member state comes from before the timeline; fetching current profiles would misattribute earlier messages. Limited account-data and presence windows must retain cursors before omitted changes to deliver the remainder. (`conduit-server/src/api/client/sync.rs`)
- 2026-10-14 — Knock membership needs `m.room.join_rules` in its auth events (spec auth-events selection lists join, invite and knock). Without it the knock check sees the default `invite` rule and rejects every knock. v11 also lets a knocker self-leave and lets kick target any non-ban membership. (`conduit/src/auth.rs`)
- 2026-10-14 — `/thirdparty/location|user` answer 404 M_NOT_FOUND when nothing is found, not `[]`: the spec defines 200 only for at least one result. (`conduit-server/src/api/client/thirdparty.rs`)
- 2026-10-14 — axum's 2 MiB `DefaultBodyLimit` silently capped media uploads below the advertised `m.upload.size` with a non-Matrix 413. Upload handlers stream the body against `max_upload_bytes` and disable the default on those routes. (`conduit-server/src/api/client/media.rs`)
- 2026-10-14 — SSRF checks must cover the address actually connected to: classify literal hosts, refuse if any resolved address is denied, give reqwest a resolver that re-applies the policy (no rebinding window), re-check the peer, follow redirects manually. `url` parses `2130706433` and `0x7f.1` as 127.0.0.1. (`conduit-server/src/api/client/safe_fetch.rs`)
- 2026-10-14 — Media blobs are content-addressed and shared; the retention task deleted a blob when one remote row expired, destroying identical local uploads. Delete only when `media_storage_path_in_use` is false. (`conduit-server/src/api/client/media.rs`)
- 2026-10-14 — Derive redactions and relations from the event log (partial jsonb indexes) instead of write-path hooks, so federated events are served like local ones. Judge a redaction against the power levels in its own `auth_events`; current state would un-redact when a moderator is demoted. (`conduit-server/src/api/client/room_content/serve.rs`)
- 2026-10-14 — Transaction replay derives a stored reply's HTTP status from its errcode, so a spec `400 M_UNKNOWN` would replay as 500. Answer deterministic `M_UNKNOWN` rejections without freezing them. (`conduit-server/src/replay.rs`, `conduit-server/src/api/client/rooms.rs`)
- 2026-10-14 — Browser e2e against conduit-server: wait on observable state only. The client's `window.__conduitClient.awaitIdle()` (sync live, no send or operation in flight) replaces sleeps; failures are simulated with Playwright route aborts. A long-poll in flight is not affected by a new route, so trigger a sync return (send a message) before expecting the next request to fail. (`client/e2e/`)
- 2026-10-14 — Clients must not trust `unread_notifications` alone: Conduit sends zeros (conduit-y99.24). Count messages from others after the user's own m.read receipt as a fallback, and persist the read marker with the room snapshot. (`client/src/core/room.ts`)
- 2026-10-14 — A persisted room snapshot trimmed to the last N events must drop its prev_batch: the stored token points before the untrimmed window and would skip events. Page from the live end (`/messages` without `from`) and de-duplicate instead. (`client/src/core/room.ts`)
- 2026-10-14 — Capability tokens are bound to device epochs, so deleting a device row and recreating the same device ID would restart at epoch 0 and resurrect old tokens. Retire the epoch on deletion and resume past it on creation. INET::TEXT renders `/32`; use `host()`. (`conduit-server/migrations/0015_account_devices.sql`)
- 2026-10-14 — Distinguish soft from hard logout at verification: if the token's epoch still matches the device row, only the time check can have failed (soft_logout true); a missing device or moved epoch is a hard logout. Round expiry up from milliseconds or tokens live shorter than the advertised expires_in_ms. (`conduit-server/src/api/client/mod.rs`)
