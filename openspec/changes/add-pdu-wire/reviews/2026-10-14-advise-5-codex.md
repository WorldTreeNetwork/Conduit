1. **C2: make valid non-join authoriser signatures observable.** [design.md:182](/Users/dukejones/work/WorldTree/Conduit/openspec/changes/add-pdu-wire/design.md:182) checks `SignedBy` for non-join memberships, but [design.md:190](/Users/dukejones/work/WorldTree/Conduit/openspec/changes/add-pdu-wire/design.md:190) ignores signatures from every non-required server. Consequently, a valid authoriser signature from another server never counts, and an otherwise valid event is rejected. Verify that authoriser for the auth decision while preserving the specified reject-versus-drop distinction. Add valid, missing and invalid non-join vectors. [Matrix v1.19 v11 rule 4.2.1](https://spec.matrix.org/v1.19/rooms/v11/#authorisation-rules) applies to every membership event.

2. **C3: keep snapshot classification separate from stored-row classification.** [design.md:414](/Users/dukejones/work/WorldTree/Conduit/openspec/changes/add-pdu-wire/design.md:414) writes a queue snapshot’s verdict into `events.id_integrity` while explicitly allowing different snapshot and row bytes. A verified snapshot could therefore mark a lossy stored row `verified`, bypassing its serve-time redaction; the reverse could wrongly withhold a valid row. Classify the stored row independently, preserving retained history, and record the snapshot verdict separately. Add a differing-snapshot/row case and align [spec.md:479](/Users/dukejones/work/WorldTree/Conduit/openspec/changes/add-pdu-wire/specs/events-and-signing/spec.md:479). Hash checks must concern the actual emitted object. [Matrix receipt validation](https://spec.matrix.org/v1.19/server-server-api/#validating-hashes-and-signatures-on-received-events).
